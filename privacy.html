Privacy Policy: Ian's Rocket Uploader

Ian's Rocket Uploader is a private tool operated by IQopolis LLC. It uploads Ian's Rocket videos to IQopolis LLC's own YouTube channel.

YouTube API Services

  • Ian's Rocket Uploader uses YouTube API Services (the YouTube Data API) to upload videos, set their titles, descriptions and thumbnails, and check their processing status.
  • By using Ian's Rocket Uploader, you agree to be bound by the YouTube Terms of Service.
  • Google's handling of data is described in the Google Privacy Policy.

What data is accessed, used and stored

  • The tool is used only by IQopolis LLC, on its own Google account. It does not offer sign-in to anyone else.
  • It accesses only IQopolis LLC's own YouTube channel: it uploads videos to it and reads the upload status of those videos.
  • It does not collect, store, sell or share any personal data or any YouTube viewer data. The only credential it keeps is IQopolis LLC's own OAuth sign-in token, stored privately on IQopolis LLC's computers. It is never shared with anyone.
  • It uses no cookies and no tracking.

Revoking access and deleting data

  • Access can be revoked at any time on the Google security settings page: myaccount.google.com/permissions.
  • The stored sign-in token is deleted when access is revoked or the tool is retired. Because no other data is stored, nothing else needs deleting. A deletion request can be sent through the contact below and is completed within 7 days.
